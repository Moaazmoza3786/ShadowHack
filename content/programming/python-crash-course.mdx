# Python Crash Course for Hackers

Python is the language of penetration testing. Metasploit modules, exploit scripts, automation tools — most are written in Python. This crash course covers everything you need to start writing your own tools.

## Why Python for Hacking?

- **Rapid development** — write a port scanner in 10 lines
- **Massive library ecosystem** — `requests`, `scapy`, `paramiko`, `pwntools`
- **Cross-platform** — runs on Linux, Windows, macOS
- **Readable** — easy to modify existing exploits
- **Default on Kali** — Python 3 is pre-installed

## Functions

```python
# Basic function
def scan_port(ip, port, timeout=1):
    """Check if a port is open. Returns True/False."""
    import socket
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(timeout)
        result = sock.connect_ex((ip, port))
        sock.close()
        return result == 0   # 0 = success = port open
    except Exception:
        return False

# Call it
if scan_port("10.10.10.5", 80):
    print("[+] Port 80 is OPEN")
else:
    print("[-] Port 80 is closed")
```

## Error Handling

```python
import socket

def connect(ip, port):
    try:
        sock = socket.socket()
        sock.settimeout(2)
        sock.connect((ip, port))
        return sock
    except socket.timeout:
        print(f"[-] Timeout connecting to {ip}:{port}")
        return None
    except ConnectionRefusedError:
        print(f"[-] Connection refused on {ip}:{port}")
        return None
    except Exception as e:
        print(f"[-] Error: {e}")
        return None
```
