# Password Cracking

Password cracking is the process of recovering plaintext passwords from stored hashes or captured network traffic. It's a core skill in penetration testing — from cracking `/etc/shadow` after a Linux compromise to cracking NTLM hashes from a Windows network.

## Understanding Password Hashing

Passwords are (should be) stored as hashes, not plaintext. A hash is a one-way function — you can't reverse it directly.

```
Password: "password123"
MD5:      482c811da5d5b4bc6d497ffa98491e38
SHA1:     cbfdac6008f9cab4083784cbd1874f76618d2a97
bcrypt:   $2b$12$EixZaYVK1fsbw1ZfbX3OXePaWxn96p36WQoeG6Lruj3vjPGga31lW
```

**Cracking strategies:**
1. **Dictionary attack** — try words from a wordlist
2. **Brute force** — try every possible combination
3. **Rule-based** — apply mutations to dictionary words
4. **Rainbow tables** — precomputed hash-to-password lookups

## Identifying Hash Types

```bash
# hashid
hashid '5f4dcc3b5aa765d61d8327deb882cf99'
# [+] MD2
# [+] MD5
# [+] MD4

# hash-identifier
hash-identifier
# Enter hash: 5f4dcc3b5aa765d61d8327deb882cf99
# MD5

# hashcat auto-detect
hashcat --identify hash.txt
```

| Hash | Example | Hashcat Mode |
|------|---------|-------------|
| MD5 | `5f4dcc3b5aa765d61d8327deb882cf99` | 0 |
| SHA1 | `5baa61e4c9b93f3f0682250b6cf8331b7ee68fd8` | 100 |
| SHA256 | `5e884898da28047151d0e56f8dc629277...` | 1400 |
| bcrypt | `$2b$12$...` | 3200 |
| NTLM | `8846f7eaee8fb117ad06bdd830b7586c` | 1000 |
| NetNTLMv2 | `user::domain:challenge:hash` | 5600 |
| WPA2 | (from .cap file) | 22000 |

## Hashcat — GPU-Accelerated Cracking

Hashcat is the fastest password cracker available. It uses your GPU for massive parallelism.

```bash
# Basic dictionary attack
hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt

# With rules (best64 is a great starting point)
hashcat -m 0 hash.txt /usr/share/wordlists/rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# Brute force (mask attack) — 8 chars, lowercase + digits
hashcat -m 0 hash.txt -a 3 ?l?l?l?l?d?d?d?d

# Combination attack (combine two wordlists)
hashcat -m 0 hash.txt -a 1 wordlist1.txt wordlist2.txt

# NTLM (Windows)
hashcat -m 1000 ntlm_hashes.txt rockyou.txt

# NetNTLMv2 (captured from network)
hashcat -m 5600 netntlmv2.txt rockyou.txt

# WPA2 handshake
hashcat -m 22000 handshake.hc22000 rockyou.txt
```

### Hashcat Mask Characters

| Mask | Character Set |
|------|--------------|
| `?l` | Lowercase letters (a-z) |
| `?u` | Uppercase letters (A-Z) |
| `?d` | Digits (0-9) |
| `?s` | Special characters |
| `?a` | All printable characters |

```bash
# Crack a 6-digit PIN
hashcat -m 0 hash.txt -a 3 ?d?d?d?d?d?d

# Common password pattern: Word + 2 digits + special
hashcat -m 0 hash.txt -a 3 ?u?l?l?l?l?d?d?s
```

## John the Ripper

John is more versatile than Hashcat — it auto-detects hash types and handles many formats natively.

```bash
# Auto-detect and crack
john hash.txt

# With wordlist
john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt

# With rules
john hash.txt --wordlist=rockyou.txt --rules=best64

# Crack /etc/shadow (after combining with /etc/passwd)
unshadow /etc/passwd /etc/shadow > combined.txt
john combined.txt --wordlist=rockyou.txt

# Show cracked passwords
john hash.txt --show

# Crack ZIP password
zip2john protected.zip > zip_hash.txt
john zip_hash.txt --wordlist=rockyou.txt

# Crack SSH private key
ssh2john id_rsa > ssh_hash.txt
john ssh_hash.txt --wordlist=rockyou.txt
```

## Capturing Hashes

### From Linux (`/etc/shadow`)
```bash
# After gaining root or reading shadow
cat /etc/shadow
# root:$6$rounds=5000$salt$hash:18000:0:99999:7:::
# user:$6$rounds=5000$salt$hash:18000:0:99999:7:::
```

### From Windows (Mimikatz)
```
mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords
# [00000003] Primary
#  * Username : Administrator
#  * NTLM     : 8846f7eaee8fb117ad06bdd830b7586c
```

### From Network (Responder)
```bash
# Capture NetNTLMv2 hashes from network
sudo responder -I eth0 -wrf

# Hashes saved to /usr/share/responder/logs/
# Then crack with hashcat -m 5600
```

## Wordlists

| Wordlist | Location | Size | Use Case |
|----------|----------|------|----------|
| rockyou.txt | `/usr/share/wordlists/rockyou.txt` | 14M passwords | General purpose |
| SecLists | `/usr/share/seclists/` | Huge | Specialized lists |
| CeWL | Generated from target website | Custom | Targeted attacks |

```bash
# Generate custom wordlist from target website
cewl https://target.com -d 3 -m 5 -w custom_wordlist.txt

# Combine with rules for better coverage
hashcat -m 0 hash.txt custom_wordlist.txt -r best64.rule
```

<InfoBox type="tip">
Always try `rockyou.txt` with `best64.rule` first. This combination cracks the majority of weak passwords in minutes. If that fails, try larger wordlists or targeted custom lists.
</InfoBox>
