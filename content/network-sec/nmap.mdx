# Nmap — Network Scanning Mastery

Nmap (Network Mapper) is the most powerful and widely-used network scanning tool in existence. Every penetration tester must master it. It's used for host discovery, port scanning, service detection, OS fingerprinting, and vulnerability scanning.

## Basic Syntax

```bash
nmap [scan type] [options] [target]

# Target formats
nmap 10.10.10.5           # Single IP
nmap 10.10.10.1-254       # IP range
nmap 10.10.10.0/24        # CIDR notation
nmap scanme.nmap.org      # Hostname
nmap -iL targets.txt      # From file
```

## Scan Types

### TCP SYN Scan (`-sS`) — Default & Stealthy
The most popular scan. Sends a SYN packet and waits for SYN-ACK (open) or RST (closed). Never completes the handshake — harder to detect in logs.

```bash
sudo nmap -sS 10.10.10.5
```

### TCP Connect Scan (`-sT`) — No Root Required
Completes the full TCP handshake. Slower and more detectable, but works without root privileges.

```bash
nmap -sT 10.10.10.5
```

### UDP Scan (`-sU`) — Slow but Essential
Many critical services run on UDP (DNS:53, SNMP:161, DHCP:67). Often overlooked by defenders.

```bash
sudo nmap -sU --top-ports 20 10.10.10.5
```

<InfoBox type="tip">
Combine TCP and UDP: `sudo nmap -sS -sU -p T:80,443,22,U:53,161 10.10.10.5`
</InfoBox>

### Null, FIN, and Xmas Scans — Firewall Evasion
These scans exploit RFC 793 behavior. They can bypass some stateless firewalls and packet filters.

```bash
nmap -sN 10.10.10.5   # Null scan (no flags)
nmap -sF 10.10.10.5   # FIN scan
nmap -sX 10.10.10.5   # Xmas scan (FIN+PSH+URG)
```

## Essential Options

### Port Specification

```bash
nmap -p 80              # Single port
nmap -p 80,443,8080     # Multiple ports
nmap -p 1-1000          # Port range
nmap -p-                # All 65535 ports
nmap --top-ports 1000   # Top 1000 most common ports (default)
nmap --top-ports 100    # Faster: top 100 ports
```

### Service & Version Detection (`-sV`)

```bash
nmap -sV 10.10.10.5
# Output: 22/tcp open ssh OpenSSH 7.6p1 Ubuntu 4ubuntu0.3
```

### OS Detection (`-O`)

```bash
sudo nmap -O 10.10.10.5
# Output: Running: Linux 4.X|5.X
#         OS CPE: cpe:/o:linux:linux_kernel:4
```

### Aggressive Scan (`-A`)
Enables OS detection, version detection, script scanning, and traceroute in one flag.

```bash
sudo nmap -A 10.10.10.5
```

## Timing Templates (`-T0` to `-T5`)

| Template | Name | Use Case |
|----------|------|----------|
| `-T0` | Paranoid | IDS evasion (very slow) |
| `-T1` | Sneaky | IDS evasion |
| `-T2` | Polite | Reduces bandwidth |
| `-T3` | Normal | Default |
| `-T4` | Aggressive | Fast, reliable networks |
| `-T5` | Insane | Fastest, may miss results |

```bash
# Fast scan for CTFs
nmap -T4 -p- 10.10.10.5

# Stealthy scan for real engagements
nmap -T1 -sS --top-ports 100 10.10.10.5
```

## Nmap Scripting Engine (NSE)

NSE scripts extend Nmap's capabilities massively. Scripts are located in `/usr/share/nmap/scripts/`.

```bash
# Run default scripts
nmap -sC 10.10.10.5

# Run specific script
nmap --script=http-title 10.10.10.5

# Run all scripts in a category
nmap --script=vuln 10.10.10.5
nmap --script=auth 10.10.10.5
nmap --script=exploit 10.10.10.5

# SMB enumeration
nmap --script=smb-enum-shares,smb-enum-users 10.10.10.5

# HTTP enumeration
nmap --script=http-enum,http-methods,http-headers 10.10.10.5 -p 80,443
```

<InfoBox type="important">
`nmap -sC -sV` is the standard starting point for almost every CTF and pentest. Memorize it.
</InfoBox>

## Output Formats

```bash
nmap -oN output.txt      # Normal (human-readable)
nmap -oX output.xml      # XML (for tools like Metasploit)
nmap -oG output.gnmap    # Grepable
nmap -oA output          # All three formats simultaneously
```

## Practical Workflows

### CTF / Quick Recon
```bash
# Step 1: Fast scan to find open ports
nmap -T4 -p- --min-rate 5000 10.10.10.5 -oN ports.txt

# Step 2: Detailed scan on found ports
nmap -sC -sV -p 22,80,443 10.10.10.5 -oN detailed.txt
```

### Real Engagement (Stealthy)
```bash
# Slow, fragmented scan to evade IDS
nmap -T2 -sS -f --data-length 25 --top-ports 1000 10.10.10.5
```

### Network Discovery
```bash
# Find all live hosts in a subnet
nmap -sn 10.10.10.0/24

# Ping sweep with ARP (faster on local network)
sudo nmap -PR -sn 10.10.10.0/24
```
