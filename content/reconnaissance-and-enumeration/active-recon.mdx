# Active Reconnaissance — Scanning & Enumeration

Unlike passive recon, **active reconnaissance** involves sending packets directly to the target. You are now interacting with their infrastructure — which means you can be detected by firewalls, IDS/IPS, and security monitoring.

**Only perform active recon with explicit written authorization.**

## TCP Fundamentals

Understanding TCP is essential for understanding how scanning works.

### The TCP Three-Way Handshake

```
Client          Server
  |──── SYN ────▶|    "I want to connect"
  |◀── SYN-ACK ──|    "OK, I'm listening"
  |──── ACK ────▶|    "Great, let's talk"
  |   [Connected] |
```

### Port States

| State | Meaning | Nmap Response |
|-------|---------|---------------|
| **Open** | Application is listening | SYN-ACK received |
| **Closed** | No application, OS responds | RST received |
| **Filtered** | Firewall dropping packets | No response / ICMP unreachable |
| **Open\|Filtered** | Can't determine (UDP) | No response |

## Nmap — The Essential Scanner

### Phase 1: Host Discovery

```bash
# Ping sweep — find live hosts
nmap -sn 192.168.1.0/24

# Disable ping (scan even if host doesn't respond to ping)
nmap -Pn 10.10.10.5

# ARP scan (local network only, very reliable)
sudo nmap -PR -sn 192.168.1.0/24
```

### Phase 2: Port Scanning

```bash
# SYN scan (default, requires root) — fast and stealthy
sudo nmap -sS 10.10.10.5

# Full connect scan (no root needed) — slower, more detectable
nmap -sT 10.10.10.5

# Scan all 65535 ports
nmap -p- 10.10.10.5

# Fast scan — top 100 ports
nmap -F 10.10.10.5

# Specific ports
nmap -p 22,80,443,8080 10.10.10.5

# Speed up with min-rate
sudo nmap -sS -p- --min-rate 5000 10.10.10.5
```

### Phase 3: Service & Version Detection

```bash
# Service version detection
nmap -sV 10.10.10.5

# OS detection (requires root)
sudo nmap -O 10.10.10.5

# Aggressive scan (OS + version + scripts + traceroute)
sudo nmap -A 10.10.10.5

# Standard pentest starting point
sudo nmap -sC -sV -p 21,22,80,139,445,8080 10.10.10.5 -oN scan.txt
```

## Web Enumeration

### Directory & File Discovery

```bash
# Gobuster — fast directory brute-forcing
gobuster dir -u http://10.10.10.5 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
gobuster dir -u http://10.10.10.5 -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,html,txt,bak

# Feroxbuster — recursive scanning
feroxbuster -u http://10.10.10.5 -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt

# Dirsearch
python3 dirsearch.py -u http://10.10.10.5 -e php,html,txt

# Nikto — vulnerability scanner
nikto -h http://10.10.10.5
```

### Subdomain Enumeration

```bash
# Gobuster DNS mode
gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt

# Amass (comprehensive)
amass enum -d target.com

# Subfinder
subfinder -d target.com

# DNSRecon
dnsrecon -d target.com -t brt -D /usr/share/wordlists/subdomains.txt
```

## SMB Enumeration

```bash
# Enumerate shares and users
enum4linux -a 10.10.10.5

# List shares
smbclient -L //10.10.10.5 -N

# Nmap SMB scripts
nmap -p 445 --script smb-enum-shares,smb-enum-users,smb-os-discovery 10.10.10.5

# CrackMapExec
crackmapexec smb 10.10.10.5
crackmapexec smb 10.10.10.5 --shares -u '' -p ''
```

## SNMP Enumeration

```bash
# Walk SNMP tree with default community strings
snmpwalk -c public -v1 10.10.10.5
snmpwalk -c private -v1 10.10.10.5

# Brute force community strings
onesixtyone -c /usr/share/seclists/Discovery/SNMP/common-snmp-community-strings.txt 10.10.10.5
```

## Standard Recon Workflow

```bash
# Step 1: Quick port scan to find open ports
sudo nmap -sS -p- --min-rate 5000 10.10.10.5 -oN ports.txt

# Step 2: Detailed scan on discovered ports
ports=$(grep "open" ports.txt | cut -d'/' -f1 | tr '\n' ',' | sed 's/,$//')
sudo nmap -sC -sV -p $ports 10.10.10.5 -oN detailed.txt

# Step 3: Web enumeration (if HTTP found)
gobuster dir -u http://10.10.10.5 -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,html,txt

# Step 4: Service-specific enumeration based on findings
# FTP → try anonymous login
# SMB → enum4linux, smbclient
# SSH → check version for known CVEs
# HTTP → nikto, gobuster, manual browsing
```

<InfoBox type="important">
Always save your scan results with `-oN`, `-oX`, or `-oA`. You'll reference them throughout the engagement and need them for your report.
</InfoBox>
